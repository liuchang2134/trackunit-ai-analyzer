## Official model photos

Retrieved 2026-09-22 from XCMG North America's official product pages and public media library. The local files are unmodified downloads; source URLs, dimensions and SHA-256 hashes are in [machines/sources.json](machines/sources.json).

The UI uses transparent-background presentation versions for XC948U, XE55U and XE80U (`*-cutout.png`), made from those official photos with AI background removal. The untouched downloads remain alongside them. Presentation cutouts illustrate the model only and should not be used to verify an individual machine's configuration or parts.
