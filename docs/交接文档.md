## 一、这是什么

辅助工程机械故障排查的工具：**网页工作台 + Chrome 侧栏插件**。不替代车联网平台，也不替代工程师判断。

核心是**一条三步链**，界面顶部那条流程条就是它的定义：

```
1 设备自动关联 → 2 AI 排查可疑部件 → 3 同 VIN 图册核对
```

| 步 | 谁在做 | 做什么 |
|---|---|---|
| 1 | **程序** | 取设备身份与遥测；身份冲突、缺采样时间都显示原因，不猜 |
| 2 | **AI** | 程序读数据做计算，模型决定读什么、何时停，并推断可疑部件（带手册页码） |
| 3 | **AI + 程序** | 把检索词标在官方图册对应行；读回真实条目给料号候选 |

**AI 的每条结论都要能追溯**——这是项目的立足点，不是附加功能。所以有引用审计、证据包、真实回放。

## 五、当前数据源是 `demo`

`.env` 里 `DATA_SOURCE` 决定读哪套数据：

| 值 | 含义 |
|---|---|
| `demo` | **当前**。一台合成 XE55U + 12 条遥测 + 一个合成故障事件 |
| `mock` | 5 台模拟设备（`M-1001`…），**没有 XE55U** |
| `trackunit_cache` | 本机从平台同步的车队缓存 |

**为什么有 `demo`**：真车队没有故障车，故障这一步在真机上看不到数据；而 `mock` 里没有 XE55U，手册查询会返回空。所以演示自带一个场景把链路走通。

**唯一"真"的一层是手册摘录**（原厂原文与页码），也是唯一需要对核的。故障事件带 `raw_payload.scenario='synthetic_scenario'` 与 `not_a_trackunit_report=true`，跟着数据走，不靠幻灯片说明。

## 七、坑与禁区（**这一节最重要**）

### 环境类

**不要反复跑全量测试。** 全量约 40–60 秒、起多个 Python 进程，本次会话中反复运行**导致机器数次闪退**。改完只跑受影响的文件：

```bat
.tmp\venv\Scripts\python.exe -m pytest tests/test_xxx.py -q
```

**`.env` 用 `load_dotenv(override=True)`**，所以**在终端设环境变量不生效**（会被 `.env` 覆盖）。要切换数据源就改 `.env`。

**改 `requirements.txt` 的 pydantic 版本前先看**：`pydantic==2.13.5` 是 `typesafe-sdk` 要求的；降到 2.10.x 会让那个可选依赖失效。

### 代码类

**`app/mock_data/` 是共享夹具，不要往里加设备。** 本次会话中我加了演示设备，结果：一个断言"5 台设备"的测试变成 6 台失败，14 个测试因为**按机型查设备**出现第二台 XE55U 而 `StopIteration`。演示数据因此独立成 `app/demo_data/`。
**`app/manual_knowledge.KNOWLEDGE_PATH` 必须作为模块常量读取。** 我一度改成调用时重新解析路径，**绕过了测试对该常量的 `monkeypatch`**，8 个手册测试失败。


**`app/manual_knowledge.KNOWLEDGE_PATH` 必须作为模块常量读取。** 我一度改成调用时重新解析路径，**绕过了测试对该常量的 `monkeypatch`**，8 个手册测试失败。

**`scripts/build_release*.py`、`verify_release*.py`、`tests/test_release_v*.py` 按固定路径读 `docs/RELEASE_*.md`。** 移动这些文档会让**测试从通过变成静默跳过**——比失败更隐蔽。

**不要把 `report` 变量覆盖成历史报告。** 它联动流程条、导出、反馈面板。历史报告用独立的 `openedReport`。

### 诚实性类（**不要破坏**）

演示页**只放真实模型输出**。曾经有一个预设的模拟案例（滑移装载机 H10101），已彻底删除，并有测试防止它复活（`tests/test_demo_path.py`）。

**不要为了演示效果伪造数据**：不要把故障塞进真车记录、不要让程序输出冒充 AI 运行（`demo_replay` 会拒绝不含模型决策的记录）、不要声称诊断准确率（没有带标签的验证集）。

界面上「模拟数据」的标识是**故意保留**的，不要为了好看删掉。

### 文档类

**文档里的数字有测试盯着**：`tests/test_competition_statement.py` 与 `tests/test_defence_outline.py` 会实时重算引用数与测试数，写错就失败。改完代码记得同步 `参赛说明.md`、`README.md`。
