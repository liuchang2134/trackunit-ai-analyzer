# 本地工况识别：模拟传感器基线

已交付可重跑训练脚本、无标签的模拟传感器CSV、数值JSON模型、独立测试报告、纯Python推理模块、只读回放API和网页“工况回放”页面。

打开本地工作区的“工况回放”，选择独立测试片段及0至479分钟起点，加载最多30分钟数据。可拖动位置或20倍速播放，查看传感器输入、识别状态及按采样点计数的分布。低得分显示未知。更换片段或起点清除旧结果，离开页面停止播放。界面来源与设备分析页面分开。

回放API为 `/assistant/work-state/episodes` 和 `/assistant/work-state/replay`，只读取测试集传感器CSV，不读取工况标签或原始物理真值。请求窗口和episode ID受限，数值模型按评价记录中的SHA256校验。

## 输入和输出

每5秒输入转速、液压压力、液压流量、地面速度及带时区的时间戳。识别挖掘、回转、卸料、怠速、行走、停机；载重/回程回转合并为回转，预热归入怠速。仅使用当前及此前最多3个采样点的值、均值和变化量，共12个特征。隐藏工况标签只用于监督目标和评价，不进入特征；设备编号、场景名、时间位置、潜在功率均不作为特征。

这些详细信号由现有模拟器的物理通道添加假设噪声得到，不是Trackunit实测字段。当前真实Trackunit数据不足以运行此分类器。模拟观测CSV与原始物理真值分别存放；不能将物理真值直接当现场传感器精度。

## 独立模拟测试

训练28段161,280点，验证7段40,320点，测试7段40,320点；原始独立episode划分保留，没有随机打散相邻行。固定随机森林64棵树、深度10、叶子最少12样本、类别均衡权重。得分阈值0.65在查看测试结果之前固定。

| 指标 | 测试集结果 |
| --- | --- |
| 六类原始预测准确率 | 90.04% |
| 宏平均F1 | 0.9078 |
| 仅预测训练集中最多类别的基线准确率 | 26.41% |
| 达到0.65模型得分的覆盖率 | 89.85% |
| 达到阈值样本的准确率 | 93.48% |
| 低得分保留未知的比例 | 10.15% |

得分是树投票结果，不是校准后的真实概率。缺失、非有限数值、越界、无时区及非递增时间样本直接返回未知。超过15秒的间隔清空历史窗口。

卸料F1为0.7427、回转为0.7741，主要混淆发生在这两类及部分挖掘转换阶段。怠速、停机、行走在此测试中为1.0，主要反映模拟器状态与传感器关系简单，不可推广为真实设备性能。没有回转角速度、操纵杆/阀信号，不能据本报告认定现场这些工况可可靠区分。

## 文件与复现

- `requirements-training.txt`：训练用scikit-learn1.7.2；安装后运行 `python scripts/train_work_state.py`。
- `data/work_state_v1/model.json`：约1.66MB的数值树，无pickle；推理不依赖scikit-learn。
- `data/work_state_v1/evaluation.json`：原始输入文件哈希、模型哈希、划分、混淆矩阵及各类指标。
- `data/work_state_v1/observations/{split}/*.csv.gz`：只有时间戳和4个模拟观测通道，没有标签。
- `app/work_state.py`：因果特征和数值模型推理。

导出模型在200个均匀抽取的测试输入上与scikit-learn概率输出误差小于1e-10。单元测试覆盖标签不进入特征、仅使用过去窗口和异常输入拒绝。这些验证针对实现一致性，不能替代真实场景验证。

后续须扩展传感器漂移等新场景，并用真实标注数据进行校准。该模型不做故障预测、剩余寿命或维修决策。

压力测试现已完成，详见 `docs/evaluation/2026-09-14-work-state-stress.md`。额外噪声下已分类样本准确率降至84.11%，得分≥0.9样本仍有4.47%错误。8,064个压力缺失点均返回未知，但后续窗口也受影响。信号冻结受影响区间覆盖率只有41.18%。这些结果说明得分不是正确率，当前模型尚未通过真实工况可靠性验证。
