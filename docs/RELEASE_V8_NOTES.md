# v8 Gemini 软件原型 · 2026-09-14

本版软件配置为 **Gemini 云端语言推理 + 本机网页、证据、目录、报告与轻量数值模型**。后端版本 `20260914.9-gemini-release`，扩展源文件版本 0.3.0。既有 v6 ZIP 和旧本地模型材料不被覆盖。

## 本版提供

| 用户任务 | 可用范围 |
| --- | --- |
| 读取设备证据 | 导入规范化数据，按来源和数据版本选择；趋势图、缺失/冲突记录提示及 CSV 下载 |
| 查询故障资料 | 由故障记录打开本地目录候选、出处、适用范围及原文检查；演示目录明确标注 |
| 工况识别 | 模拟柴油液压挖掘机的六类状态与未知状态，数值随机森林回放 |
| 冷却热事件预警 | 120 个独立模拟设备实验，当前/过去数据特征，15 分钟预警窗口，观测曲线、未知/停机状态和误报对照 |
| 预警带入排查 | 创建匹配设备及截止时点的模拟数据版本，后端核对证据；不自动提交云端请求 |
| Gemini 排查接口 | 凭据留在后端，受约束工具和出处、错误分型、总时限和有限重试；失败不冒充报告 |
| 历史与检查反馈 | 本地记录、原文反馈、设备/数据版本隔离及续查接口；云端成功流程仍待验收 |
| 平台辅助扩展 | Chrome/Edge 侧栏源文件、两个固定本机端口、设备 URL 与运行配置核验；真实安装仍待验收 |

## 准确解释实验结果

冷却模型对 24 个独立模拟测试片段中的 8 个热事件提前识别 8 个，中位提前量 15 分钟；95°C 观测阈值对照为 7/8、中位 9 分钟。但模型产生 36 个误报片段、0.268/有效小时，对照为 19 个、0.141/有效小时。模型测试误报率超过验证阶段设置的 0.1 预算。不能称为实机准确率、零件故障诊断或整体优于对照。完整定义见 [冷却数据卡](COOLING_WARNING.md)。

100°C 持续 180 秒只是此模拟实验的目标定义，不是制造商限值。工况模型同样尚无实机标定。示例选择服务于交互演示，评价包含全部独立测试片段。

## 未完成的项目要求

1. **Gemini 完整真实成功链路**：此前最新请求返回项目/模型每日免费额度耗尽，上限 20。没有把本版的本地数据自检当作云端分析成功，也没有自动更换模型或收费方案。
2. **XGSS 线上故障手册**：仍缺获准身份、故障码字段/位置及查询模式契约。没有有效线上手册跳转；提供的认证跳转接口也不是正式备件库搜索接口。
3. **真实备件与现场验证**：缺适用机型/VIN 的正式目录及维修结果标签；不能直接用于采购或验证故障预测效果。
4. **真实平台侧栏安装**：浏览器安装及 iframe 设备切换仍未验收。源文件和逻辑测试不能替代它。
5. **另一台实体电脑与最新版竞赛材料**：本机独立解压/新虚拟环境验证不等于新电脑验收；原 v7 Proposal、旧答辩稿和视频没有冒充与本版全部一致的完成材料。

## 包与安装行为

发布配置默认为 mock、自动同步关闭、Gemini key 留空。无需云端配置即可通过 `-DemoOnly` 启动数据演示，但点击 AI 分析仍要求配置 Gemini。没有其他模型替代输出。

本版包括完整冷却模拟数据及必要工况资源，保留 ECharts 许可证和说明。模拟车队的设备 ID、序列号、客户和位置经过统一替换；不带 `.env`、真实缓存、私有目录、诊断历史或用户 XGSS 公钥。初始化只写入本地运行数据，不改写包内源码和示例。

安装步骤和自检命令见 [安装指南](RELEASE_V8_GUIDE.md)。实际生成的 ZIP SHA-256、解压目录、Python 和依赖版本、自检输出记录在开发项目的本版验收证据中，不把自检结果预写成真实 API 或新电脑成功结论。
