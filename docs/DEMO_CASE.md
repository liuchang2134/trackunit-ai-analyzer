## 数据来源

`data/demo_case.json` 是可随 Git 分发的预设案例，通过只读 `GET /assistant/demo-case` 提供。

- 代码定义来自用户提供的 TV12U / 260224 协议表第66行；仅保留该案例所需定义，不分发完整内部原表。
- 设备为 `SIM-TV12U-DEMO-001`，没有真实 VIN；假设协议适用，未经过实机匹配。
- 所有数值、现场现象、检查和复测结果均为虚构。14分钟为压缩展示时间，不能用作维修效率指标。
- 行走响应百分比为演示归一化指标，不声称 Trackunit 或 CAN 提供该传感器。
- AI 段落为预设解释；没有调用 Gemini，不代表实时生成或成功调用记录。
- XGSS 未被调用；没有虚构正式料号、价格或库存。
- 演示不写入设备列表、真实任务或诊断历史。
