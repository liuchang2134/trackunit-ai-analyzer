# 冷却预警误报改进实验（结果产生前的约定）

目标：提高现有模拟预警的可用性；原 v1 模型、数据、回放引用和发行包保持可复核。

## 预先约定

- 只调整报警阈值和连续确认分钟数，不重新训练森林。候选阈值 0.4、0.5、0.6、0.7、0.8、0.9、0.95；连续确认 2、3、4 分钟。分数不是校准故障概率。
- 使用原验证集及 48 个新验证片段（24 nominal、24 shifted），不读取原 test 结果来选参数。新种子 2026091400 + 10000 + j；每组六种场景均衡。
- shifted：热容 260–560 kJ/K、散热系数倍率 0.75–1.20、轴功率产热比例 0.38–0.62；节温器起点 70–76°C、跨度 13–19°C；风扇起点 75–81°C、跨度 14–20°C；冷却液传感器白噪声 σ=0.35°C、片段固定偏差 ±0.6°C、8 小时线性漂移 ±0.5°C。这些均为模拟假设，不代表某型号真实参数。
- 候选必须在每个验证组达到：事件召回率 100%、已检出事件提前量中位数至少 10 分钟、误报段数不超过 0.1/可评估小时。合格候选按最差组误报率最小、合计误报分钟最少、最小组提前量最大、阈值更高、确认分钟更多依次选择。若无合格候选，记录最接近者为未通过实验，不能部署。
- 冻结候选文件和 SHA 后，才生成 96 个新测试片段（48 nominal、48 shifted），种子 2026091400 + 20000 + j。不得依据测试结果再次选择参数。测试与所有既有训练/验证/测试片段种子不交叉。
- 同片段比较原森林策略、候选策略和 95°C 连续 2 分钟基线。沿用 v1 的事件、资格、误报段定义，额外报告误报分钟，避免通过延长报警段数美化结果。
- 接入门槛：两个新测试组各自事件召回率至少 90%、检出事件数不低于旧策略、中位提前量至少 10 分钟且不低于温度基线、误报率不超过 0.1/可评估小时且比旧策略降低至少 25%、误报分钟不多于旧策略。任何一项失败都不替换当前页面模型。有限模拟通过也不等于真实故障预测验证。
- 保存每分钟分数、状态、资格和标签供独立核算；事件真值始终只用于离线评价。代码/协议/模型/数据 SHA 记录在结果中。

## 工作项

- [ ] 实现明确的报警连续确认参数，保留旧契约默认值；检验缺测、停机、高温、前缀因果性。
- [ ] 运行验证选择、冻结候选，然后一次性运行新测试与独立统计核对。
- [ ] 如达到预设门槛，另行接入新版本并验收页面；否则保存负面结果和明确下一步。

方法参考：[scikit-learn 阈值选择文档](https://scikit-learn.org/stable/modules/classification_threshold.html)，训练、阈值选择和最终评估数据分离。本次沿用森林，不调用新版本库接口，不增加依赖或外部 API 请求。
