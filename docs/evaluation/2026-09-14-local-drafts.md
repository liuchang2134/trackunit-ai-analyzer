# 本机排查草稿验收（2026-09-14）

当前开发版 `20260914.12-local-drafts` 增加“保存本机草稿 / 恢复已存草稿 / 撤销恢复”，记录问题、现场观察、任务与报告关联。草稿存本机，不依赖成功 AI 报告。用法见 [操作说明](../LOCAL_INVESTIGATION_DRAFTS.md)。

实际复现了旧页面的丢失问题：填写模拟检查记录、刷新、重新选择相同 SIM 冷却数据版本，观察输入为空。本次修复后完成以下实际浏览器检查：

- 保存后刷新，选回同一设备/数据版本，显式恢复原问题、观察及任务，恢复后的焦点回到观察框。
- 切到另一 SIM 备件设备，输入为空且无已存草稿；返回原设备后未提交的新观察仍在。
- 输入新观察，恢复旧草稿，再撤销恢复，新观察取回。
- 通过本机 API 对本次 SIM 验收草稿作一次竞争更新；旧页面保存得到 409，新版本未被覆盖。重新读取、审阅恢复、撤销恢复并保存的恢复路径可用。
- 实测发现冲突后旧版恢复按钮仍可用，虽不能覆盖服务端记录但会误导操作；已修正为先重新读取，再允许恢复，并加了 Node 回归测试。
- 从相同的模拟冷却预警再次“带入设备排查”，新问题进入表单，但现场观察没有清空。历史反馈入口同样去掉了清空观察的代码；本轮没有在真实 Gemini 报告上验证这条历史入口。
- 自然窄窗口宽 567、高 631，文档实际宽 552；草稿按钮高 44，无横向页面溢出。没有设置浏览器视口覆盖，也没有声称完成其他断点或维修人员测试。

完整 Python 测试 367 项通过，有 6 条既有依赖弃用警告；完整 Node 测试 33 项通过。新增 API 测试覆盖源/设备/版本隔离、关联报告归属、冲突、写入失败保留旧版、损坏文件和输入约束；前端状态测试覆盖迟到响应、编辑中的保存快照与恢复撤销。测试与实际草稿操作均没有调用 Gemini、Trackunit 或 XGSS。

实际保存的是明确标注为模拟的验收观察；不是维修结论，也没有生成新的诊断历史。当前多页面冲突保护按单进程后端验证，未验收多个后端进程并发写入。
