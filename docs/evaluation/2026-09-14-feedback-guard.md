# 人工反馈明确矛盾检查

新增 app/feedback_validation.py，比较 summary 与 operator:feedback 原文。仅识别已覆盖的表达：原文报告目视观察而摘要否认进行了检查；原文说不能确认传感器损坏而摘要称无损坏。返回原文与冲突句，交由现有六步上限重写流程；持续矛盾不生成完成报告。不会把选定的检查流程或 not_observed 结果当成已执行所有检查。

验证：13 个直接用例覆盖中英文矛盾、未完成测量、其他部件未检查、否定和无反馈；2 个流程用例覆盖重写通过及持续失败。全套 224 passed，6 条既有弃用警告。

本地 qwen3:8b 中英文各重放一次同一模拟反馈，见 2026-09-14-feedback-guard-live.json（代码及检查模块哈希、请求、逐步决策、报告）。两次完成的最终摘要均未触发新检查，因此这次实际模型运行不能证明冲突后重写成功。重写分支仅有受控测试证据。

中文摘要仍遗漏目视观察；英文出现“The sensor model XE135U matches the machine”，把整机型号误称传感器型号，并把历史故障记录直接描述为当前活跃。这些不在本次检查范围内，语义验收仍未通过。原文在 data_facts 独立保留，不代表错误摘要已经修复。

该模块是有限表达检查，不是通用自然语言事实验证，未覆盖所有说法、假设句和复杂否定。旧报告与原始失败记录保持不变。v4 ZIP 尚未更新。
