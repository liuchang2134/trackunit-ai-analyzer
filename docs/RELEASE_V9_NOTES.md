# v9 软件原型：当前工作区同步

本版对应后端 `20260914.11-ai-request-status`、辅助扩展源文件 0.3.0。它将 v8 软件包之后的设备检索和排查交互修改纳入新的 ZIP；原 v8 文件保留。AI 仍采用 Gemini，轻量数值模型和资料在本机。

## 相比 v8 的新增内容

| 用户任务 | 本版行为及范围 |
| --- | --- |
| 找到设备与数据版本 | 按机型、序列号、编号和片段名称搜索，筛选来源与未解决/冲突记录；选择后进入准确数据版本。空记录不等于设备正常 |
| 判断是否提交 AI | 排查前看到最近完整请求结果和时间；状态刷新不调用云端，已有配置不等于当前可用，历史状态不承诺额度恢复 |
| 从故障资料继续操作 | 继续排查按钮紧随故障状态；原文按需展开，候选适用范围与出处保留，故障码自动带入表单 |
| 键盘与窄窗口操作 | 关闭资料返回原按钮焦点；交接聚焦问题框并显示状态。开发浏览器已检查桌面、窄窗口和 390 像素视口 |
| 报告与反馈 | 模拟 Gemini HTTP 响应测试走通结构化结果、候选、保存、原文反馈与续查；原报告不可变、不同设备反馈不能串用 |

保留既有趋势、数据质量提示、CSV、合成工况、冷却热事件预警、目录筛选及平台侧栏源文件。详细状态行为见 [AI 请求状态](AI_REQUEST_STATUS.md)。

## 安装时的真实状态

首次配置为 mock、自动同步关闭、Gemini key 留空。包里没有开发机器的故障状态文件；首次显示密钥未配置，不显示开发机的历史额度错误。已有数据、缓存、目录、历史与凭据不随包分发。文档中的历史额度案例是当次联调事实，不能推断新使用者账号的额度。

包内说明和原始交互截图是开发版本验收记录。设备查找的浏览器检查使用十个本地版本，超过二十个结果的翻页、大车队性能及屏幕阅读器仍未完整验证。安装自检使用包内五台模拟车队设备和一个模拟导入案例。

## 仍需完成

- 真实 Gemini 完整诊断、出处和候选、保存及检查反馈续查。当前最新实际请求为此前日额度失败，模拟响应不替代这项验证。
- 获准使用的 XGSS 身份、准确故障参数契约及正确手册跳转；正式备件目录与机型/序列号适配核对。跳转接口不等于备件搜索接口。
- 实际浏览器扩展安装与平台设备切换；另一台实体电脑安装。
- 实机工况、维修结果及预测效果验证。冷却模拟模型误报高于温度对照，不能声称已满足现场告警要求。
- 与当前版本对应的新演示视频和完整业务验收。v9 Proposal/答辩稿是单独文档，包内未将历史视频伪装成当前演示。

安装和本地自检见 [安装指南](RELEASE_V9_GUIDE.md)。本机新虚拟环境通过只能证明所检查的本地安装流程；不证明云端可用、官方资料接通或不同电脑已验证。
