# 0.9.31 — 故障配件、连续传感器与图册读取更新

源码标识：`20260925.4-button-check`。插件版本：`0.9.31`。

## 本次更新

- 主页面集中展示当前及历史故障、AI 配件推荐和参考估价；连续传感器分析保留在“故障预测”入口。
- 支持 Advanced Sensors 分批导出全部可用通道，按通道身份合并；最多同时显示四条曲线，不限制为仅采集四项。
- 风险卡片中的“潜在故障配件”直接读取同 VIN 图册并生成候选，不覆盖主故障分析结果。
- 改进中文及英文检索词匹配、父子分类查找和润滑/传动方向区分；仅使用图册实际返回的零件身份。
- 支持图册自包含 SVG 与嵌入图片的安全转换；补图时保留已成功取得的零件与资料，区分未提供图示和加载异常。
- 历史通信故障候选保留核查条件，避免仅因故障文字或名称相似便建议更换电源或总成。
- 图册维护标注入口使用当前分析检索词；同设备切换故障后重新获取，避免使用旧缓存。
- 采集中关闭侧栏时取消页面作业；所有者租约失效后清理任务并恢复原页面选择。

## 边界与升级

XGSS 部分分类、料号或源图可能未开放，页面保留成功资料并显示覆盖范围，不用其他分类的图片冒充。AI 风险线索和候选部件仍需结合设备适配、现场检查及适用手册核对。

拉取源码后安装 `requirements-xgss.txt` 中的新增依赖，并在 Chrome 扩展管理页面重新加载 `extension` 目录。运行中的后端需在没有正在执行的采集/分析时重启，才能加载更新后的 Python 代码。

此更新发布到 Git 主分支；先前 Releases 的复现包保持其发布时点的内容，不能把其历史版本等同于本次源码。
