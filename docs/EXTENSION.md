# Chrome 侧栏插件

当前安装、连接、自动识别及权限范围统一见 [插件说明](../extension/README.md)，请加载当前项目的 `extension` 文件夹。

插件在侧栏打开时识别 Trackunit 设备详情页的 UUID，将其交给本机助手匹配同一台设备并自动载入已有实测数据。多个版本时保留已有选择，否则选择最新有效采样版本；采样时间相同则稳定选择一个并说明，日期未知也提供默认版本并说明。仍可手动切换版本，不混入模拟数据或其他设备。没有对应数据时提示同步或导入；切换设备不会自动调用 AI 或同步外部接口。

当前 AI 默认为 DeepSeek，密钥保留在后端。页面设备识别不表示已经读取页面全部遥测值或绕过 Trackunit API 权限；设备识别、实际数据加载和 AI 分析分别显示状态。

当前网页构建为 `20260915.7-auto-device-data`，插件仍为 `0.5.0`。已安装该版本时无需重新安装，保存未提交草稿后点击“重新连接”即可载入新网页。首次安装或从旧插件升级时仍按插件说明加载，并允许指定 Trackunit 站点的访问权限。

用户截图已证明侧栏识别了正确设备 UUID，也揭示了旧网页的多版本待选阻塞。本次修复的浏览器验收另见 [当前验收状态](PROJECT_ACCEPTANCE_STATUS.md)，不以源码测试代替实装验证。
