# Chrome 侧栏插件

插件源码位于项目根目录的 `extension` 文件夹，直接包含 `manifest.json`。本说明自包含，可随未附带扩展 README 的历史发布包阅读。版本以包内 `manifest.json` 和 Chrome 扩展管理页显示为准；历史包不等同于当前开发版本。

## 安装与连接

1. 打开 Chrome 扩展管理页，启用开发者模式，点击“加载已解压的扩展程序”，选择包内 `extension` 文件夹。
2. 启动该包的本机后端，再点击浏览器中的插件图标打开侧栏。插件通过 8892 或 8890 端口连接；可在“连接设置”切换端口和重新连接。使用对应发布包的启动指南启动服务。
3. 在 Trackunit 打开设备详情页，在侧栏点击“读取当前设备”。支持自动跟随的版本会在同一窗口切换设备时自动更新；没有该功能的历史版本仍需手动读取。
4. 等待助手确认设备匹配，并核对机型、数据来源和采样时间。没有匹配数据时先同步或导入；存在多个数据版本时按页面提示核对所选版本。
5. 重新连接、修改端口或打开独立演示可能重载工作区。操作前保存尚未提交的输入。

## 设备、AI 与图册

插件读取 Trackunit 设备详情页 URL 中的 UUID，以及标签页标题显示的设备编号，用于关联已有数据或查询该机快照。设备编号只是查询提示，API 返回的 `metadata.assetId` 必须与页面 UUID 完全一致。设备识别不等于读取了所有页面遥测，也不绕过 Trackunit API 权限。“已连接”只表示本机页面和后端配置完成握手；模型名称及分析成败以实际后端和工作区结果为准。

0.6.1 与后端构建 20260915.9 起，新增设备没有本地数据时会尝试读取该机的 Trackunit 资料；失败保留具体状态和手动重试入口。网页中的演示入口会同步暂停跟随，点击“读取当前设备”恢复设备排查。新版会跳过不兼容的旧服务，避免显示已连接却缺少读取功能。更新后需在扩展管理页重新加载插件，仅重连本机端口不会更新插件脚本。

具备 XGSS 图册读取按钮的版本，可先在 Trackunit 关联设备，再打开该设备对应的 XGSS 官方图册，选中分类并显示零件明细，点击“读取当前 XGSS 图册”。系统核对可见 VIN/PIN 与本机设备，读取当前可见行供 AI 比较候选。没有此按钮的历史版本只提供页面入口，不具备图册内容回传功能。

## 权限与验证范围

升级扩展后，Chrome 可能提示新增站点权限；按当前包的清单允许所需的精确站点，不需要允许所有网站。旧版本的权限范围不能据此推断为新版本权限。图册采集不会读取 cookie、隐藏应用状态或会话令牌，也不自动采购。

代码测试、成功读取 UUID、后端连接、AI 请求、实际图册读取是不同验证步骤。历史包的验证范围以该包发布说明为准；当前开发版的实际验收记录保留在项目内，不将历史测试当作最新生产成功证据。
