# Chrome 侧栏插件

当前安装、连接、自动识别及权限范围统一见 [插件说明](../extension/README.md)，请加载当前项目的 `extension` 文件夹。

插件在侧栏打开时识别 Trackunit 设备详情页的 UUID，将其交给本机助手匹配同一台设备。工作区保留来源和数据版本，多个实测版本需明确选择；没有对应数据时提示同步或导入。切换设备不会自动调用 AI。

当前 AI 默认为 DeepSeek，密钥保留在后端。页面设备识别不表示已经读取页面全部遥测值或绕过 Trackunit API 权限；设备识别、实际数据加载和 AI 分析分别显示状态。

已安装扩展需要在 Chrome 扩展管理页重新加载，并允许指定 Trackunit 站点的访问权限。工具无法直接操作扩展内部页面，因此源码测试与真实安装后的验收分别记录。
