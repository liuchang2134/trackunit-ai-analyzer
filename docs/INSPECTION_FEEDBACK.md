# 检查反馈与继续分析

在“诊断记录”展开原报告，点击“检查反馈 / 继续分析”。选择对应检查项、观察结果和本机时间，填写说明后保存。每条反馈是独立的本地文件，包含原报告、设备、检查项、观察时间和保存时间；原报告不覆盖。

点击“带已保存反馈继续分析”切换回原设备和原数据集，确认问题后开始分析。新报告保留原记录 ID，将该记录下最近 5 条反馈及总条数保存为 operator:feedback 证据。更换设备会清除关联。当前只携带直接父记录的反馈，不自动遍历更早的记录链。

反馈均为未经验证的人工观察。“未观察到”不能排除故障，“已观察到”不能确认根因，系统不会据此完成维修或下单。模拟演示输入应在说明中明确标注。当前不支持编辑、删除、人员签名或附件。

接口：GET /assistant/history/{record_id}/feedback 和 POST 同路径。时间必须带时区且不能晚于保存时刻；检查项必须属于原报告；继续分析要求设备和数据集都与原报告一致。文件内容哈希用于检测意外损坏，不是防篡改数字签名。

2026-09-14 验证：全套 155 项测试通过；页面实际保存一条明确标注的模拟反馈，切回原模拟设备后由 qwen3:8b 完成三次工具查询并保存新报告。摘要保留缺少传感器损坏证据的判断，但仍可能在摘要重复检查步骤，不能据单例认定全面语义可靠。浏览器已验证保存、计数更新和继续分析流程。
