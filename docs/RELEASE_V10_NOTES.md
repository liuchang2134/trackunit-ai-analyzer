# v10 状态与验收范围

本包把网页 `.16-cooling-evidence` 与 Chrome 插件 0.4.0 放在同一交付目录。相对封存 v9，加入本机草稿、待处理工作台、设备排查任务及导出、XGSS 官方页面入口、插件设备匹配确认，以及扩大模拟预警评估。

源码阶段已验证设备版本隔离、任务历史、草稿冲突与恢复、XGSS 模拟响应显示、插件模拟消息和独立网页设备切换、桌面/窄屏冷却回放交接。冷却相关 41 项测试通过；此前完整 Python 413 项和 Node 45 项通过。安装包本身的核验结果应以随交付提供的独立验收记录为准，不以源码测试替代。

这些缺口没有被模拟应答或单元测试代替。XGSS 返回页面属于官方系统，当前没有结构化手册正文或正式备件适配／库存 API。冷却扩大测试识别 28/31 次模拟事件、误报 0.215 段/可评估小时，未达到预设门槛；失败的报警参数候选没有采用。
