# 项目实现与验证状态（公开版）

当前版本说明见 [RELEASE_0.9.31.md](RELEASE_0.9.31.md)，安装与配置见 [README](../README.md)。本文只说明可公开的功能与验证边界，不发布现场设备标识、客户遥测、故障时间线或本机运行记录。

## 当前功能

| 功能 | 实现与验证边界 |
|---|---|
| Trackunit 设备关联 | Chrome 插件与本机工作台共享设备上下文；切换设备核对身份与数据版本。外部账户权限由各接口分别判定。 |
| 当前与历史故障 | 可使用已取得的官方事件或页面可见记录，保留来源、状态与覆盖范围。空记录不等于无故障；历史已解除事件不作当前故障。 |
| AI 配件推荐 | 先解释选中故障与检索方向，再从实际取得的同 VIN 图册中选择条目。料号、来源和故障关联校验由后端执行。 |
| XGSS 图文读取 | 后台直读目录、零件表和二维图纸；保留既有插件备用链路。图纸绑定对应分类，读取失败保留已取得的资料及未覆盖范围。 |
| 图片补取与缓存 | 主动重读可跳过缓存并补取缺图；已验证图片、身份与版本限制继续保留。 |
| 参考估价 | 按用户录入的有来源单价与数量计算；缺价显示待询价，不冒充 XGSS 正式报价或自动采购建议。 |
| 连续传感器读取 | 支持发现高级传感器并分批取得页面导出，多采样率合并、单位分类、缺口分段及状态编码保留。可取得通道随设备、权限和时间范围变化。 |
| AI 风险线索 | 基于有效连续证据生成风险假设及图册检索词；不将单点快照、停机零值或缺失值当作故障。 |
| 潜在故障配件 | 在二级风险卡内读取同设备 XGSS 并显示候选与图示；保持首页故障研究和估价独立。 |
| 邮件准备 | 备件内容先预览，再按配置和明确操作发送。未配置或未完成送达验证时，不显示已经通知相关人员。 |

## 验证方式

定向自动化检查覆盖：设备和数据版本隔离、原始来源校验、当前与历史事件区分、故障到零件依据、原图绑定、查询容量、超时与取消、缓存失效与补图、页面主操作以及传感器证据接续。既有图册或建议恢复不应造成重复收费模型请求。

应用案例使用实际设备资料进行功能核验；XC948U 只是选取的一台案例，不代表产品只支持该型号，也不构成所有设备与配置均已验证的声明。现场原始记录与详细评估日志保留本机。

下列内容必须按实际部署环境单独确认：

1. Trackunit 及 XGSS 的当前登录、授权与设备适用范围。
2. Chrome 原生插件的页面识别、分批导出和图文回传。浏览器辅助采集、手工导入和离线测试不能替代该检查。
3. 邮件发送配置与实际送达。预览通过不等于发送成功。

## 尚不能据此宣称的效果

- 风险分析尚未完成故障发生时间、故障概率或剩余寿命的实车标定。
- 图册身份与名称匹配不证明部件损坏，备件准备仍取决于实际检查、配置核对和有效依据。
- 测试用例数量与局部功能验收不能代替诊断准确率、全机型覆盖或实际维修效果。
- XGSS 读取目前不保证覆盖全部维修手册、特殊多图分类及保养包；取得的资料以当前权限和真实返回为准。
