## 2026-09-15 Trackunit 自动识别

已在用户登录的 Trackunit Manager 中打开一台 XE55U，确认详情页路径为 `/assets/<UUID>/status`。该 UUID 与本机两份导入历史数据的设备 ID 一致，通过同样的设备交接地址打开助手后，网页只列出该设备的两份实测版本，没有混入模拟设备。随后用户提供的已安装侧栏截图显示了正确 UUID，但网页停在“请选择该设备的数据版本”，因此自动识别尚未衔接到数据展示。

0.5.0 在侧栏打开时读取当前标签地址，并跟随同一窗口的设备页面切换；可暂停跟随，演示模式自动暂停。离开详情页后显示旧设备保留提示，过期回复不能把旧设备标为当前关联。同一设备切换子页面不重载工作区；换设备保留草稿，进行中的 AI 分析先完成再应用新设备。

`20260915.7-auto-device-data` 修复数据版本选择：仅载入同一 UUID 的实测缓存或用户导入实测资料，保留仍有效的已有选择；否则默认选择最新有效采样版本。采样时间相同时按记录数、版本 ID 稳定选择一个并说明；无有效采样日期时也给出默认版本，明确日期未知。用户可手动切换核对，默认选择不代表资料完整。插件仍为0.5.0，无需重新安装，通过“重新连接”载入新网页；不会因此自动同步接口或调用 AI。
