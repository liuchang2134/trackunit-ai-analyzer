# v6 交付说明

本版仍是本地参赛原型，默认模拟数据，不代表真实设备诊断验收。

## 本版变化

- 默认模型、安装提示、运行检查与包内配置统一为 qwen3.5:9b。本机已通过实际后端调用核对模型名称、历史保存和报告内容；模型权重不随包分发。
- 趋势数据不足时，模型必须选择有来源的数据核查步骤才能结束分析。
- 摘要指令明确区分目录与手册、型号与整机配置、告警记录与独立故障，并要求解释已计算的趋势指标。包含实际评测成功与失败记录，摘要仍可能出现不准确措辞。
- 加入 XGSS 生产接口说明、RSA 本地加密模块和可选依赖清单。生产地址由接口方补充确认，尚无服务端联调成功证据。仍缺故障码请求示例、授权身份和业务字段映射。
