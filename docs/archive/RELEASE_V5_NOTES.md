# v5 原型交付说明

本版在 v4 基础上纳入以下已实现功能：

- 诊断记录直接查看完整保存报告、人工反馈和备件资料，并单独导出历史 Markdown，无需再次运行 AI。
- 报告正文保留人工反馈原文、观察时间和填报结果，明确标注未经验证；网页及下载内容已与保存记录核对。
- 补充无备件候选时的资料核查步骤、分析与采样时间一致性检查、已覆盖表达的工时正常误判及人工反馈矛盾检查。
- 增加约 35 秒检查反馈评审片段，以及相应实测报告、原始失败输出和网页导出示例。

报告中的 AI 摘要仍有遗漏、整机型号与零件型号混淆等语义缺陷。有限表达检查不能验证所有判断，原始人工反馈和程序计算的数据仍应对照查看。本包是本地可演示原型，不是已通过现场诊断验收的产品。

材料版本：完整 Proposal、答辩稿 v4 及 44 秒模拟短片继续保留，近期变化以本说明及 evaluation 记录补充。新增检查反馈短片是实际页面定格，片尾明确标出当时错误，适用于内部评审，不能作为算法准确性的证明。

部署、数据、模型获取方式见 START_HERE.md。本包不含真实凭据、实际设备缓存、私有历史目录、Python/Ollama 运行时和模型权重。新电脑验收、完整断网冷启动、实际侧栏安装联调、正式备件资料与现场效果仍未完成。v4 ZIP 保持原样。
