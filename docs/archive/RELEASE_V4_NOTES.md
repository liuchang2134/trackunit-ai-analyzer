# v4 原型交付说明

本版包含本地服务与侧栏源码、模拟演示数据与备件模板、工况分类模型及回放、参赛计划书、10 页可编辑答辩稿及 PDF、讲稿、44 秒模拟功能视频、典型报告和评测记录。

报告新增数据事实与待核实 AI 解释分区。数据事实由程序根据已有证据生成，覆盖来源、分析时点、采样时点、指标和备件筛选结果。附带 browser-export-facts-demo.md/JSON 为实际网页运行后的模拟报告示例。此分区不证明 AI 解释已全部正确。

答辩稿 v4 同步了报告分工、视频及已验证部署范围。计划书保留完整项目方案和边界，近期验证细节以本说明及 evaluation 文档为补充。视频 v1 早于数据事实分区的界面更新，演示已实现的模拟流程，未展示最新分区；它包含界面定格和动态回放、经过剪辑，不能用于响应时间评估，也没有覆盖侧栏及完整检查反馈操作。

已有部署证据分别覆盖同机新 Python 虚拟环境、独立解压运行、后端启动与重复启动、模型卸载后的网页重新加载，以及限定 Python 进程仅允许环回连接的运行。整机断网、整个 Ollama 服务冷启动和新电脑验收仍未完成。

双语固定案例保留完整输出和失败。压缩模型最终上下文的实验出现退步，已撤回，不在当前运行代码中。当前自由摘要仍有语义缺陷，数据事实与原始证据供复核。实机故障预测、正式备件适用性、维修收益和服务人员试用尚未验证。

本包默认模拟数据，不包含真实账户凭据、实测缓存、私有历史记录、Python/Ollama 运行时或模型权重。真实 API 接入、模型与依赖安装见 START_HERE.md。此包为可演示原型交付，未声称项目全部验收完成。
