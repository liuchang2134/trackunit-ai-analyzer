## 安装或升级

1. 在 Chrome 扩展管理页开启开发者模式，点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的 `extension` 文件夹。
2. 已安装旧版时，点击该扩展的“重新加载”。0.6.0 新增 XGSS 站点和按需脚本读取权限；Chrome 提示时允许 `https://xgss.xcmg.com/*`，然后刷新已打开的 XGSS 页面。无需允许所有网站。
3. 在项目目录运行 `start_local.cmd --port 8890`。0.7.0 默认优先连接 8890（设置中可改回 8892，保存的端口偏好优先）。需要后端构建 `20260915.9` 或更新版本；旧服务即使能打开页面也会被跳过。仅点击侧栏“重新连接”不会更新扩展脚本，升级后必须在扩展管理页重新加载。
4. 打开 Trackunit 设备详情页，点击扩展图标打开侧栏。等待设备资料读取完成并核对机型与采样时间。“已连接”仅表示本机服务可用。网页优先选择同一平台 UUID 的实测数据版本；该机已在本机有数据时直接按当前 UUID 显示，不需要先确认设备编号。没有本地版本时尝试读取该机的 Trackunit 资料，失败显示原因，不选择其他设备代替。

## 返回当前机器

点击“读取设备”，或在暂停状态点击“自动跟随 · 关”，可返回当前 Trackunit 机器并恢复设备跟随。设备切换正在等待分析结束、资料加载失败、没有权限或只有设备基本资料时会分别提示，不将 TV12U 演示当作当前设备。

## 故障排查与图册读取

### AI 查找并生成备件建议

在真实 Trackunit 设备的“备件与维修建议”中，填写现象并选择“模拟”或“人工报告”，点击“查找备件与维修资料”。助手先用 DeepSeek 生成部件方向，然后在后台标签页打开同 VIN 的官方图册，按已有分类标签查找相关内容，保存后再生成候选与检查建议。每个料号通过来源条目解析，不由模型生成。

0.9.3 适配了实际 XGSS iView 分类树。分类切换时等待表格稳定；必要时向下滚动目录，最多四次。当前每次最多提取六页、保存记录最多八页，不自动采购、提交工单或遍历所有折叠分类。结果会提示未命中检索词，不能视作完整 BOM。手册正文未读取时，检查建议明确标为 AI 建议。

升级后必须重新加载 Chrome 扩展并重新打开侧栏。源码与包测试通过不代表真实侧栏自动链路已验收；当前人工验证记录见项目 `docs/evaluation/2026-09-21-xgss-research.md`。

### 手动读取当前页

1. 先在 Trackunit 打开需要调查的机器。插件自动跟随同一 Chrome 窗口的设备切换；分析期间的设备切换由网页处理，避免串机。
2. 在网页工作区填写故障或使用明确标注的测试故障进行分析。测试故障不是 Trackunit 已上报事件。
3. 从工作区打开该机器的 XGSS 页面，在官方页面选中需要的图册分类并显示“零件明细”。使名称、物料编码等列在屏幕中可见。
4. 切到 XGSS 标签页后，侧栏保留已选设备的调查。在“图册”中点击“读回当前图册条目”。该操作只读取已渲染、当前可见的表格行，以及页面显示的 VIN、分类等信息。
5. 助手将图册显示的 VIN/PIN 与所选机器、数据版本核对。匹配后保存到本机，供 AI 根据部件名称、位置和排查证据比较候选。需要新分类时，在 XGSS 手动选中并重新读取；当前读取结果代表该次可见行，不代表全部图册。
6. 在工作区查看资料读取状态和备件与维修建议。每个实际料号保留图册采集来源；AI 推断本身不生成订购料号。

页面不显示 VIN、存在多个 VIN、无法识别表格、没有有效料号或设备不一致时，不导入任何条目，也不覆盖此前已保存的有效快照。无料号不代表无对应备件。分页、滚动后尚未渲染的行、其他折叠分类及 iframe 访问限制都可能影响读取。插件不自动翻页、采购或提交工单。

## 权限与数据范围

- `sidePanel`：显示侧栏。
- `activeTab`：响应用户在当前标签页的操作。
- `scripting`：用户启动资料查找或图册读取后，执行受限目录导航和可见 DOM 提取。
- 精确站点：`manager.trackunit.com`、`new.manager.trackunit.com`、`xgss.xcmg.com` 的 HTTPS 页面。
- 本地界面仅嵌入 `http://127.0.0.1:8892` 与 `http://127.0.0.1:8890`，通过当前 iframe、端口及连接编号核对消息。

没有全站权限、cookie 权限、隐藏应用状态读取或网络拦截。后台标签页的资料采集只在用户启动本次任务后进行，切换设备或停止任务会取消后续动作。Trackunit 跟随提取详情 URL 中的 UUID，以及标签页标题显示的设备编号；编号仅作查询提示，后端必须核对 API 返回的 UUID，不能只凭编号认定身份。XGSS 读取提取可见 VIN、机型/配置（若显示）、分类路径、零件名称、料号、序号、数量及明确的维修正文区域。实际会话 URL、查询参数、令牌、cookie、输入框和整页正文不会进入资料记录。来源地址仅保留 XGSS 官网根地址，具体定位依赖采集时间、分类和图号。

相关现象与已读取零件/手册摘录按用户授权交由本机后端配置的官方 DeepSeek 分析；发送前排除 VIN、平台设备 ID 和页面地址。多页来源和建议存于本机 `data/local/xgss-research`，不随 Git 发布。

图册快照存于被 Git 忽略的 `data/local/xgss-catalog-context`，按设备、VIN 和数据版本隔离，并保留稳定来源编号供分析引用。尚未确认与实际设备关联的模拟数据不能导入真实图册；可以在实测机器上单独输入标注为测试的故障。

## 连接与验证

“已连接”表示本机页面和后端配置完成握手，模型调用是否成功以实际排查结果为准。重新连接或更改端口会重新载入工作区，未保存的输入将丢失。进入 XGSS 之前必须在本次侧栏会话中确认设备；关闭或重载侧栏后请先回到 Trackunit 重新关联。

自动化测试覆盖设备自动跟随、窗口与数据版本隔离、连接恢复、可见表格解析、VIN 缺失/冲突、空表、重复行、隐藏/屏幕外行、旧请求拒绝、敏感 URL 不外传，以及本地快照的设备校验和完整性校验。表格测试使用明确标记的测试料号，不能作为生产成功证据。实际 XGSS 页面及 Chrome 安装验证以项目当前验收记录为准。
