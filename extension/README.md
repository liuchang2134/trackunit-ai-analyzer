# 机联智检 Chrome 侧栏 · 0.6.2

配合本机机联智检网页后端使用。源码目录 `extension` 可直接加载；无需前端编译。工具为独立辅助产品，并非徐工官方产品。

0.6.2 更新徐工蓝白页头、官方字标和图标；当前设备与主要操作保持可见，图册工具和连接详情收进折叠区。品牌来源见 [素材说明](assets/SOURCES.md)。

## 安装或升级

1. 在 Chrome 扩展管理页开启开发者模式，点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的 `extension` 文件夹。
2. 已安装旧版时，点击该扩展的“重新加载”。0.6.0 新增 XGSS 站点和按需脚本读取权限；Chrome 提示时允许 `https://xgss.xcmg.com/*`，然后刷新已打开的 XGSS 页面。无需允许所有网站。
3. 在项目目录运行 `start_local.cmd --port 8890`。侧栏优先连接保存的端口，默认检查 8892，再尝试 8890。0.6.1 需要后端构建 `20260915.9` 或更新版本；旧服务即使能打开页面也会被跳过。仅点击侧栏“重新连接”不会更新扩展脚本，升级后必须在扩展管理页重新加载。
4. 打开 Trackunit 设备详情页，点击扩展图标打开侧栏。等待设备资料读取完成并核对机型与采样时间。“已连接”仅表示本机服务可用。网页优先选择同一平台 UUID 的实测数据版本；没有本地版本时尝试读取该机的 Trackunit 资料，失败显示原因，不选择其他设备代替。

## 从演示返回当前机器

点击“读取当前设备”，或在暂停状态点击“自动跟随：关”，可返回当前 Trackunit 机器。网页内进入演示会同步暂停插件跟随，按钮和说明使用同一状态；恢复后强制回到设备排查。设备切换正在等待分析结束、资料加载失败、没有权限或只有设备基本资料时会分别提示，不将 TV12U 演示当作当前设备。

## 故障排查与图册读取

1. 先在 Trackunit 打开需要调查的机器。插件自动跟随同一 Chrome 窗口的设备切换；分析期间的设备切换由网页处理，避免串机。
2. 在网页工作区填写故障或使用明确标注的测试故障进行分析。测试故障不是 Trackunit 已上报事件。
3. 从工作区打开该机器的 XGSS 页面，在官方页面选中需要的图册分类并显示“零件明细”。使名称、物料编码等列在屏幕中可见。
4. 切到 XGSS 标签页后，侧栏保留已选设备的调查。点击“读取当前 XGSS 图册”。该操作只读取已渲染、当前可见的表格行，以及页面显示的 VIN、分类等信息。
5. 助手将图册显示的 VIN/PIN 与所选机器、数据版本核对。匹配后保存到本机，供 AI 根据部件名称、位置和排查证据比较候选。需要新分类时，在 XGSS 手动选中并重新读取；当前读取结果代表该次可见行，不代表全部图册。
6. 在工作区查看导入状态，继续分析或填写检查反馈。每个实际料号保留图册采集来源；AI 推断本身不生成订购料号。

页面不显示 VIN、存在多个 VIN、无法识别表格、没有有效料号或设备不一致时，不导入任何条目，也不覆盖此前已保存的有效快照。无料号不代表无对应备件。分页、滚动后尚未渲染的行、其他折叠分类及 iframe 访问限制都可能影响读取。插件不自动翻页、采购或提交工单。

## 权限与数据范围

- `sidePanel`：显示侧栏。
- `activeTab`：响应用户在当前标签页的操作。
- `scripting`：仅在点击图册读取按钮时执行可见 DOM 提取。
- 精确站点：`manager.trackunit.com`、`new.manager.trackunit.com`、`xgss.xcmg.com` 的 HTTPS 页面。
- 本地界面仅嵌入 `http://127.0.0.1:8892` 与 `http://127.0.0.1:8890`，通过当前 iframe、端口及连接编号核对消息。

没有全站权限、cookie 权限、隐藏应用状态读取、网络拦截或后台页面采集。Trackunit 跟随提取详情 URL 中的 UUID，以及标签页标题显示的设备编号；编号仅作查询提示，后端必须核对 API 返回的 UUID，不能只凭编号认定身份。XGSS 读取只提取可见 VIN、机型/配置（若显示）、分类路径、零件名称、料号、序号和数量。实际会话 URL、查询参数、令牌、cookie、输入框和整页正文不会传回助手。来源地址仅保留 XGSS 官网根地址，具体定位依赖采集时间、分类和图号。

图册快照存于被 Git 忽略的 `data/local/xgss-catalog-context`，按设备、VIN 和数据版本隔离，并保留稳定来源编号供分析引用。尚未确认与实际设备关联的模拟数据不能导入真实图册；可以在实测机器上单独输入标注为测试的故障。

## 连接与验证

“已连接”表示本机页面和后端配置完成握手，模型调用是否成功以实际排查结果为准。重新连接、修改端口或切换到独立演示会重载工作区，请先保存未提交输入。进入 XGSS 之前必须在本次侧栏会话中确认设备；关闭或重载侧栏后请先回到 Trackunit 重新关联。

自动化测试覆盖设备自动跟随、窗口与数据版本隔离、连接恢复、可见表格解析、VIN 缺失/冲突、空表、重复行、隐藏/屏幕外行、旧请求拒绝、敏感 URL 不外传，以及本地快照的设备校验和完整性校验。表格测试使用明确标记的测试料号，不能作为生产成功证据。实际 XGSS 页面及 Chrome 安装验证以项目当前验收记录为准。
